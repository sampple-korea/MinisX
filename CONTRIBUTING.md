# Contributing

MinisX is a personal project, so there is no roadmap or review SLA. Issues and pull requests
are welcome, but I may be slow to answer and may not merge everything.

- **Bugs and ideas:** [open an issue](https://github.com/sampple-korea/MinisX/issues). The app's
  Settings → Feedback → "Submit GitHub issue" pre-fills your version and device.
- **Pull requests:** small, focused changes are easiest. Please make sure it builds
  (see [BUILDING.md](BUILDING.md)) and describe what you changed and why.
- **A good issue has:** platform and version (Settings → About), what you expected and what
  happened, steps to reproduce, which model/provider was selected, and logs if the app produced
  any (Settings → Logs).
